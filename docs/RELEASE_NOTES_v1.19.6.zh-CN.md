# FlyPPTTimer 1.19.6 更新说明（相对 1.19.4）

## Bug 修复
- **持续置顶桌面**：修复计时器窗口、多屏叠加窗口及排练控制条在切换全屏演示、任务栏或其他窗口后被遮挡的问题，持续保持在最顶层且不抢占焦点。
- **WPS PDF 兼容性**：兼容 WPS Prometheus 整合模式（`wps.exe` + `wpspdf.exe`）与独立模式，修复 WPS PDF 全屏播放时总计时、逐页计时与页码读取失效的问题。
- **快速翻页稳定性**：修复 PowerPoint / WPS 快速滚轮翻页或短暂采样空档时页码闪烁、逐页计时器被清空以及窗口反复缩放的问题。
- **跨演示软件文稿切换**：修复默认使用 PowerPoint 但临时用 WPS 打开 PPT 时，手机端点击“切换”无法选中并前置 WPS 窗口的问题，同时按进程类型精确匹配，避免同名文稿切错软件。
- **手机端退出演示软件**：修复手机端点击“退出演示软件”在部分 PowerPoint / WPS 场景下无效的问题。
- **稳定性与并发加固**：加固后台文稿监测与远程服务状态锁，防止后台异常引发级联崩溃。

## 新增功能
- **文稿列表类型识别（PPT / PDF）**：电脑端“演示工作区”、电脑端“设置 - 文稿规则”以及手机端文稿列表统一增加柔和底色区分、左侧色条与 `PPT` / `PDF` 类型微徽章（自适应浅色 / 深色主题）。
- **文稿列表快速搜索与筛选**：电脑端“演示工作区”与手机端文稿列表新增实时文件名搜索及 `全部 / PPT / PDF` 类型筛选。
- **“关闭所有文稿”替代“关闭最近文稿”**：电脑端与手机端同步将不常用的“关闭最近文稿”替换为“关闭所有文稿”（带二次确认，不退出软件本身）。
- **手机端跨软件操作感知**：手机端执行“关闭所有文稿”或“退出演示软件”时，二次确认弹窗会明确提示当前目标软件（PowerPoint 或 WPS 演示），防止误操作。
- **通用全屏计时与PDF上传支持**：支持识别外部全屏演示画面自动计时，支持手机端上传 PDF 文稿并保留原文件名（自动加入待控列表，PDF 保持桌面端手动翻页）。
- **“超时后继续计时”自定义**：在行为设置中统一提供超时样式配置，超时后支持负号前缀、自定义文字/背景颜色与正向累计已超时长。

## 体验与性能优化
- **动态排版与自适应**：支持按文稿页码读取能力自动切换单行（4×1）/ 双行（2×2）排练控制条与主窗口布局，同步优化“打开 / 切换 / 当前”三态标识。
- **流畅度与资源开销优化**：主界面全屏窗口扫描降频至 150ms，减少计划执行的窗口扫描次数。
- **默认配置与交互细节**：新安装默认关闭语音提醒，默认开启文件浏览与接收且无需密码；情景快捷键支持 F1–F12 单一绑定互斥；手机端 PPT 指令超时调整为 23 秒，匹配桌面端最久 20 秒响应等待。
- **授权与发布加固**：保留既有在线/离线激活协议的同时，加固本地权限核对逻辑并启用 Release 符号剥离与体积优化。
