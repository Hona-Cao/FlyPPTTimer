# Inspiration acknowledgement

The early FlyPPTTimer exploration was inspired in part by **old9/ppttimer**.

FlyPPTTimer later moved to an independent implementation. The current project
does not intentionally reuse old9/ppttimer source code, icons, images, sound
assets, UI, or its AHK build chain.

This note is retained as a courtesy acknowledgement and development-history
record. Licensing and third-party details are maintained centrally in
[`THIRD_PARTY_NOTICES.md`](../THIRD_PARTY_NOTICES.md).
