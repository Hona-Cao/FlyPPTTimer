# FlyPPTTimer 4.0 用户指南（简体中文）

> 适用版本：`4.0.0-alpha.1`（工作分支 `agent/v4-foundation`）
> 这是 4.0 重构的预览指南，覆盖 WPF 单入口后的正式使用方式。功能语义与 v0.30.2 保持一致。

## 1. 4.0 有什么变化

- **WPF 唯一正式入口**：普通计时、大屏计时、远程电脑端、设置与“时间到”画面全部由 WPF 接管，旧的 WinForms 界面已不再承担正式入口。
- **两个可执行文件同目录发布**：
  - `FlyPPTTimer.exe`：主程序（托盘、计时、演示联动、远程监听）。
  - `FlyPPTTimer.Settings.exe`：独立的 WPF 设置窗口，从主程序托盘菜单或设置入口打开。
- **设置即保存即生效**：在设置窗口点击“保存并关闭”后，主程序会自动重载配置并应用，无需手动重启计时。
- **“时间到”全屏画面**改为 WPF 窗口，支持多屏关闭与释放。
- **经典设置回退已移除**：4.0 不再保留旧版 WinForms 设置窗口作为兼容入口，配置完全由 WPF 设置覆盖。

## 2. 启动与托盘

1. 运行 `FlyPPTTimer.exe`。
2. 任务栏托盘出现 FlyPPTTimer 图标。
3. 右键托盘图标打开菜单：
   - **设置**：打开 WPF 设置窗口（`FlyPPTTimer.Settings.exe`）。
   - **远程控制**：打开 WPF 远程电脑端窗口（含地址、二维码、演示文稿控制与断开设备）。
   - **开始/暂停**、**停止并重置**、**显示/隐藏计时窗口**等快速操作。
   - **退出**。

## 3. 设置窗口（WPF）

设置窗口共六个页面，右下角“保存并关闭”会把全部修改一次性写回配置并让主程序重载；未完成修改可点“取消”。窗口底部会提示未保存状态与校验错误。

### 计时
- 默认时长、计时模式（倒计时/正计时）、到零后继续超时、到时动作（停止 / 黑屏 / 结束放映 / 自定义）。
- 计时窗口宽度。
- 自动行为：全屏时自动开始、离开全屏时停止、离开全屏时重置、暂停/继续时闪烁、暂停时闪烁时间。

### 文件规则
- 为指定 PowerPoint / WPS 演示文稿保存独立时长、计时方式和启用状态。
- 支持添加文件、删除已勾选、清空。
- 批量修改：勾选多条规则后设置“批量时长 / 批量模式”并应用到已勾选。
- 同一路径只保留一条规则。

### 提醒与声音
- 提示 1、提示 2、计时结束三组提醒；每组可启用、语音播报、提前秒数、声音文件、闪烁样式与节奏。
- 超时前缀文字、超时文字颜色、超时背景颜色。

### 外观与显示
- 显示计时器窗口、始终置顶、无边框。
- 配色方案、形状、文字颜色、背景颜色、闪烁背景。
- 字号、宽、高、背景不透明度、文字不透明度。
- 多屏：所有屏幕同时显示，或指定单屏；大屏计时器（仅扩展屏，可选目标屏）。
- 默认点位（九宫格）、水平 / 垂直百分比微调。

### 快捷键
- 鼠标穿透、锁定窗口、最小化到托盘、关闭按钮行为。
- 全部全局快捷键可查看与修改；重复键会被拒绝并提示。

### 远程与其他
- 远程控制：启用、使用随机端口、端口、重新生成访问令牌（令牌不显示在界面中）。
- 语言：简体中文 / English / 跟随系统（更改后主程序重启完全生效）。
- 启动时检查更新（默认关闭）。
- 配置导入 / 导出 / 恢复默认 / 打开配置目录 / 打开日志目录。

## 4. 手机或浏览器遥控

1. 从托盘菜单打开“远程控制”。
2. 让手机与电脑处于同一局域网（Wi-Fi / 以太网 / 热点）。
3. 扫描窗口中的二维码，或在手机、平板、另一台电脑浏览器打开局域网地址。
4. 控制计时、时长、计时方式、窗口显示、闪烁和电脑静音；按当前文稿规则重新计时。
5. 浏览文稿、开始放映、翻页、黑白屏、结束放映、关闭当前文档。
6. 一键“断开全部设备”会轮换访问令牌并使旧链接失效。

> 远程控制仅用于可信局域网，通过访问 token 验证。不要把端口映射到公网，不要公开有效二维码、完整远程地址或 token。

## 5. 大屏计时器

1. 连接扩展显示器。
2. 设置 → 外观与显示 → 启用大屏计时器并选择扩展屏。
3. 大屏窗口为可缩放标准窗口，可移动、缩放、最小化或最大化；只用于扩展屏，不占用主屏。

## 6. 配置与迁移

- 配置文件：`FlyPPTTimer.config.json`（与 `FlyPPTTimer.exe` 同目录）。
- 从 v0.30.2 升级：首次启动按 `SchemaVersion` 运行一次幂等迁移，保留字体、提示文字、声音和逐页规则等用户字段；未知字段 round-trip 保留。
- 自定义声音保存在 `alert-sounds/`，安装升级不会删除。
- 配置原子写入并带时间戳备份；设置窗口的“恢复默认”会重置为出厂值。

## 7. 快捷键速查

| 按键 | 操作 |
|---|---|
| `F3` | 开始或暂停 |
| `F4` | 停止并重置 |
| `F5` | 显示 / 隐藏普通计时窗口 |

完整快捷键在设置 → 快捷键中可查看与修改。

## 8. Alpha 注意事项

- 4.0.0-alpha.1 为重构预览，未正式发布 Release / Tag。
- 行为与 v0.30.2 等价，但建议重要活动前在目标设备上完整测试：演示联动、显示位置、声音、手机连接与多屏。
- 不满意预览时，可继续使用 v0.30.2 稳定版。

## 9. 本地文件位置

- `FlyPPTTimer.config.json`：设置和规则。
- `logs/`：运行与错误日志。
- `alert-sounds/`：自选提示音的本地副本。
