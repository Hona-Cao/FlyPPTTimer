# FlyPPTTimer 4.0 人工测试计划

> 适用版本：`4.0.0-alpha.1`
> 目的：覆盖自动化 CI 无法验证的真实环境行为（多屏 / 混合 DPI、Office/WPS、音频、热键、安装升级、手机远程）。
> 自动化门槛见 [V4_ARCHITECTURE.md](V4_ARCHITECTURE.md) 第 11 节；行为等价见 [V0302_PARITY_MATRIX.md](V0302_PARITY_MATRIX.md)。

## 0. 前置条件

- Windows 10/11 x64，已安装 .NET 10 运行环境（自包含单文件发布已内置）。
- `FlyPPTTimer.exe` 与 `FlyPPTTimer.Settings.exe` 同目录。
- 一台扩展显示器（多屏与大屏用例）。
- 一部手机与电脑同一局域网（远程用例）。
- 一台装有 Microsoft PowerPoint 与/或 WPS 演示的电脑（演示联动用例）。
- 一份 v0.30.2 的 `FlyPPTTimer.config.json`（升级迁移用例）。

## 1. 启动与单实例

| # | 步骤 | 期望 |
|---|---|---|
| 1.1 | 双击 `FlyPPTTimer.exe` | 托盘出现图标，无普通计时窗口（默认隐藏） |
| 1.2 | 再次双击 `FlyPPTTimer.exe` | 不出现第二个进程，已运行实例获得焦点 |
| 1.3 | 右键托盘 → 设置 | `FlyPPTTimer.Settings.exe` 启动，标题“FlyPPTTimer 设置” |

## 2. 计时核心（等价 v0.30.2）

| # | 步骤 | 期望 |
|---|---|---|
| 2.1 | `F3` 开始，`F3` 暂停，`F3` 继续 | 计时按模式累计，暂停冻结 |
| 2.2 | `F4` 停止并重置 | 回到初始状态 |
| 2.3 | `F5` | 普通计时窗口显隐切换 |

| 2.5 | 到时动作=结束放映 | 正在放映的演示文稿结束 |
| 2.6 | 全屏自动开始 / 离开停止 / 离开重置 | 按设置联动 |

## 3. WPF 设置六页

逐页打开，修改后点“保存并关闭”，确认主程序行为即时变化、窗口关闭、托盘仍在。

| # | 页 | 关键检查 |
|---|---|---|
| 3.1 | 计时 | 默认时长、模式、到时动作、窗口宽度生效 |
| 3.2 | 文件规则 | 添加演示文稿规则；勾选多条做批量时长/模式；同路径不重复 |
| 3.3 | 提醒与声音 | 三组提醒启用/语音/提前秒数/声音文件/闪烁；超时前缀与颜色 |
| 3.4 | 外观与显示 | 置顶、无边框、配色、形状、字号、不透明度；多屏/大屏；九宫格点位与微调 |
| 3.5 | 快捷键 | 鼠标穿透、锁定、最小化到托盘、关闭行为；重复键被拒 |
| 3.6 | 远程与其他 | 远程启用/端口/重生成令牌；语言切换；检查更新开关；导入/导出/恢复默认/打开目录 |

## 4. 设置保存后主程序重载

| # | 步骤 | 期望 |
|---|---|---|

| 4.2 | 设置中改配色并保存关闭 | 普通计时窗口即时换色 |
