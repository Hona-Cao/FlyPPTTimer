# FlyPPTTimer v1.18.0

[English](RELEASE_NOTES_v1.18.0.md) · [用户指南](USER_GUIDE.zh-CN.md)

本说明仅比较上一公开正式版 **v1.17.2**。v1.18.0 包含未单独公开发布的 v1.17.3 诊断与连接恢复改进。

## 新增

- **独立的简单／自定义提醒配置**，支持目标前、计时结束与实际超时后的提醒。新安装使用简单模式；旧的未标记设置和情景保留自定义模式。
- **可选排练悬停控件——免费、默认关闭：**重置、重新开始、暂停、继续。独立菜单在鼠标离开后约 700 毫秒收回，保持 2 DIP 间距，适配计时器而不移动主读数；鼠标穿透时完全隐藏。
- **本轮加时——遥控 Pro：**运行／暂停的有限时长本轮可增加 30 秒或 1 分钟，多次累计，不修改默认时长、文件规则或情景；重置／重新开始清除延长。
- **诊断中心——免费：**查看本地状态、复制安全摘要、导出诊断报告。报告排除令牌、激活材料、文稿路径／内容、原始配置和日志。

## 改进

- 运行／暂停时切换提醒模式或应用任意情景，包括当前情景，均需桌面确认新一轮；取消保留本轮，确认清除计时反馈并保留运行／暂停状态。
- 电脑遥控设置突出手机连接、二维码与同网说明；电脑端连接技术设置集中于默认折叠的高级详情。
- **演讲复盘——免费：**摘要显示有效逐页累计用时、与最终目标的比较及累计用时最长页；延长后显示原计划、增加时间与最终目标，无限制不做目标比较。
- 复盘新增与明确选定的同文稿 **Pro 排练基准**的有效用时比较，保留原有详情和节奏信息。
- 中英标签、浅／深色可读性和对话框展示更加统一；新配置使用小圆角计时器，已保存形状不变。
- 浏览器大屏断线时保留最后有效画面，提示重连并自动重试。

## 修复

- 遥控服务状态正确反映监听／连接故障，便于识别服务停止并重启。
- 改善浏览器大屏请求顺序、超时和过期响应处理。
- 编辑提醒不再覆盖未启用的另一套配置；免费版运行自定义结束前最近启用点、计时结束和超时后最近启用点，不删除额外保存点。
- 修复排练菜单边框、尺寸、重绘和弹窗清理缺陷，仍支持已配置的提醒闪烁。
- 修正客户端许可错误分类、到期处理和授权相关设置操作。

## 已知限制

- 未到期体验在程序重启后仍需联网重新确认，原始**服务端 168 小时截止时间**不会重置。


**升级：**先备份配置和自定义提示音。已有设置与复盘历史继续可读，免费版保留本地使用流程与一个可用情景。**远程控制整体，包括手机计时／文稿控制和浏览器大屏，均需 Pro。**额外高级配置未启用时仍保留；版本限制详见[用户指南](USER_GUIDE.zh-CN.md#pro)。
