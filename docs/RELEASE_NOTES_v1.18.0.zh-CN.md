# FlyPPTTimer v1.18.0

升级基线：**v1.17.2**，即上一公开正式版。v1.18.0 已包含未单独公开的 v1.17.3 诊断与可靠性改进。

## 提醒与新一轮计时

- **简单 / 自定义：**新安装默认使用简单模式；旧配置及没有模式标记的情景快照迁移为自定义模式。两套配置独立保存，情景也保留两套；编辑或切换不会覆盖另一套。
- 简单模式提供提前、时间到、超时后开关、两个时间偏移，以及共用的声音 / 闪烁 / 语音效果。自定义模式保留详细编辑器并新增超时后节点。超时后提醒仅在实际进入超时且策略允许继续计时时触发。
- 运行或暂停时，应用任意情景（包括当前情景）或切换提醒模式，需要在桌面确认开始新一轮。取消保留本轮；确认清除已用时间和提醒/逐页反馈，保留运行或暂停意图。停止时可直接切换。手机在本轮进行中切换情景时，请在桌面确认。

## 可选悬停控制菜单

**免费，默认关闭：**在“设置 → 控制设置 → 显示排练控制条”开启并应用。鼠标靠近计时器后展开独立的小型菜单，菜单有独立外角；离开计时器及菜单约 **700ms** 后收回。菜单与计时器保持 **2 DIP** 间距，通常在右侧，靠近屏幕右边缘时改到左侧，始终不移动或压缩计时器主体。

重置使用圆角方块图标，清零并停止；重新开始使用圆形箭头图标，清零后运行；暂停 / 继续使用暂停 / 播放图标，分别仅在运行 / 暂停状态可用。菜单适配实时颜色、透明度、主题、形状及自动/自定义高度。**开启鼠标穿透时，菜单完全不出现，也不保留可点击控制窗口。**

已修复普通状态多余边框、原生/渲染尺寸同步和弹窗释放生命周期缺陷；配置的提醒边框仍正常显示。这些修复针对已确认的重绘/生命周期问题；现场偶发“双可见区域/浅色遮罩”报告仍需物理确认。新配置默认形状为 **RoundedSmall（圆角矩形·小）**，升级不会强制覆盖旧用户已保存的形状。

## 手机控制与演讲复盘

- **Remote（Pro）：**+30 秒 / +1 分钟可累计延长正在运行或暂停的有限时长本轮；暂停仍保持暂停。停止、结束和无限制状态不能延长；重置/重新开始清除延长。按钮不修改默认时长、情景或文件规则。
- 连接界面突出手机控制、二维码和同一局域网说明，技术信息放在默认折叠的“高级详情”。编辑并应用已保存时长是另一项操作；运行/暂停时应用时长，在手机确认后开始新一轮。
- **演讲复盘（免费）：**摘要展示有效逐页累计用时、相对最终目标的提前/超时及累计用时最长页。发生延长时显示**原计划 + 增加时间 + 最终目标**。无限制记录不比较目标；历史与详细逐页统计继续保留。
- **Pro 基准比较：**与用户明确选定的同一文稿历史复盘比较有效用时，独立于目标比较；不会自动选择排练基准。

## 相对 v1.17.2 的诊断与可靠性改进

从“设置 → 其他设置 → 诊断中心”或托盘入口打开诊断中心，可复制安全摘要或导出诊断报告，包含程序、演示观察、显示器、Remote、浏览器大屏、授权摘要及更新状态。导出不含令牌、激活材料、文稿路径/内容、原始配置或日志；刷新不会开始体验或联系授权/更新服务。

Remote 在监听或连接线程故障后正确恢复停止/故障状态。浏览器大屏串行请求、限制请求及正文读取超时、拒绝过期响应，断线保留最后有效画面并自动重连，提供中英提示。客户端许可错误及到期处理修复已包含在可执行文件中。

## 免费 / Pro 与升级注意

免费包含核心本地计时、两套提醒模式、**一个最接近时间到的启用自定义提前节点 + 时间到 + 一个最接近时间到的启用超时后节点**、一个可用情景、悬停菜单、诊断中心及完整基础复盘。Pro 增加 Remote（含延长）、浏览器大屏、多自定义节点/情景及排练基准/节奏比较。没有 Pro 时，额外配置继续保存但不运行；恢复 Pro 后重新可用。

升级前建议备份配置和自定义提示音；既有设置和历史记录继续兼容。7 天体验仅在用户明确确认后开始。**未到期体验重启后仍需联网重新确认，服务端原始 168 小时期限不会重置。**更宽松的重启后离线体验规则尚未决定。授权服务修复目前仅存在于源码和本地模拟测试，**尚未部署生产**；本说明不宣称新的服务端撤销或体验行为已上线。

真实 Office/WPS、声音、物理局域网/手机、多屏/分数缩放拖动锁定穿透及确认框交互仍需手工验收，隔离/软件测试不能替代这些检查。正式便携版与安装版通过 [GitHub Releases](https://github.com/Hona-Cao/FlyPPTTimer/releases) 和 [Gitee Releases](https://gitee.com/hona-cao/fly-ppttimer/releases) 提供。
