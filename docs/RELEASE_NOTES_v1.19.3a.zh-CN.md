# FlyPPTTimer 1.19.3a 更新说明

这是 1.19.2 之后的测试版，只修了两处会直接影响使用的问题，功能和设置项与 1.19.2 完全一致。

## 1. 换了默认演示软件之后，手机遥控打不开文稿

- 之前：先把 WPS 设成默认程序，后来又改回 PowerPoint，再用手机打开文稿时，程序仍然去找 WPS，结果打不开，或者打开到了错的程序里。
- 现在：每次都按你当前在 Windows 里设置的默认演示软件打开，不会再沿用上一次的连接。

## 2. 一份放映结束后，紧接着打开下一份文稿会卡住

- 之前：上一份放映刚退出就打开下一份，偶尔会一直停在加载中，只能重开软件。
- 现在：会自动重试；如果仍然打不开，就改用 Windows 默认方式打开，然后接管真正打开的那份文稿。上一份文稿不会被保存，也不会被关闭。

## 说明

- 这是测试版，用来验证上面两处修复。如果你没遇到过这两个问题，继续用 1.19.2 正式版就可以。
- 安装版可以直接覆盖安装，个人设置会保留。
