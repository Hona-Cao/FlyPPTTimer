# FlyPPTTimer v1.19.0

Compared with v1.18.0:

## Presentations & Timing

- Set timing on or off for each presentation, synced across desktop Settings, presentation lists and mobile.
- Play and navigate untimed PPTs normally, with timer displays updated when switching presentations.
- Control PPTs opened from USB drives or File Explorer, without accidentally controlling a previously selected deck.
- Recover previously managed presentations that are still available on disk.
- Filter presentations by source, open files quickly and manage multiple entries with clearer file details.
- Stop and reset timing as soon as a slideshow ends, preventing unwanted restarts.
- Keep the timer running briefly after an accidental fullscreen exit from the same presentation; adjust or disable the default five-second grace period.
- Use a distinctive timer color during accidental-exit protection.
- Improve fullscreen detection and automatic timing for WPS and PDF readers.
- Start timing directly from the rehearsal strip without opening a PPT, with Pause and Resume controls.

## Mobile Control & File Receiving

- Receive PPTX files over your local network; upload multiple files from your phone, track progress and cancel transfers.
- Choose a save folder and automatically add received files to the presentation list.
- Use a persistent receiving link with optional password protection that you can set, change or remove.
- See receiving availability, connection status and upload results on desktop and mobile.
- Distinguish manually added presentations from received uploads and filter by source.
- Use Timer, Presentation and Conference Control pages, with swipe navigation between them.
- Enjoy larger text and shorter mobile presentation cards; long-press anywhere on a card to reorder it.
- Improve narrow-screen layouts, scrolling and protection against accidental drag actions.
- Make phone Remote available automatically with Pro; QR codes follow the current service state after reconnecting.
- Share a separate read-only timer-display QR code without granting control access.

## Conference Backgrounds & Speakers

- Manage and preview conference background images, choose a default and display them when needed.
- Show backgrounds using Fill, Fit, Stretch, Tile or Center.
- Switch backgrounds instantly or with fade, slide, wipe and zoom effects.
- Choose the audience display and optionally restore the background after a presentation ends.
- Temporarily hide conference backgrounds during keyboard or mouse activity in Duplicate mode, then restore them after inactivity.
- Bulk-import speaker photos, change their order and names, and link a PPT to each speaker.
- Show speaker introductions from your phone and hand off safely to a linked PPT when ready.

## Projection & Large Displays

- Switch between Duplicate, Extend, PC Screen Only and Second Screen Only from desktop or mobile.
- Add confirmation and timeout recovery to display switching, and fix mobile status getting stuck on Switching.
- Configure PowerPoint Presenter View separately from Windows projection modes.
- Improve timer-window positioning and recovery after display, resolution or scaling changes.
- Refine the local fullscreen timer and its hover controls, fixing button overlap and re-enabling behavior.
- Improve time, page number, per-slide timing, colors and fonts in the read-only browser display.

## Settings, Appearance & Access

- Reorganize the nine Settings pages with consistent bilingual labels, option groups and light/dark themes.
- Bring file receiving, conference backgrounds and speakers into a more compact, consistent desktop interface.
- Adjust text and background opacity independently, with smoother precision-wheel and Settings scrolling.
- Preview Pro features and their screens without activating Pro.
- Deactivate online and free a device slot when changing computers, with immediate activation-status updates.
- Improve startup license checks, offline grace and renewal validation, and fix false device-limit warnings.
- Manage licenses in bulk, edit notes and archive licenses from the admin dashboard.
- Separate phone-control, read-only viewing and upload permissions, and exclude connection credentials from exported settings.
