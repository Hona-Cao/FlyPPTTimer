# FlyPPTTimer v1.19.0

相较 v1.18.0：

## 演示文稿与计时

- 新增逐文稿“启用计时”开关，电脑设置、文稿列表和手机端同步。
- 不计时的 PPT 仍可正常放映和翻页，切换文稿时自动处理计时显示。
- 临时从 U 盘或文件管理器打开的 PPT 也可遥控，避免误控此前选中的文稿。
- 新增历史文稿找回，重新加入仍在原位置的文件。
- 文稿列表新增来源筛选、快速打开及批量管理，文件信息更清楚。
- 结束放映后立即停表复位，避免旧放映状态让计时意外重启。
- 新增同一文稿意外退出保护，默认 5 秒，可自行调整或关闭。
- 意外退出保护时使用醒目的计时颜色提示当前状态。
- 改进 WPS 和 PDF 阅读器的全屏识别与自动计时。
- 排练控制条可在没有打开 PPT 时直接启动计时，支持暂停和继续。

## 手机遥控与文件接收

- 新增局域网文件接收，手机可批量上传 PPTX，查看进度、结果并取消上传。
- 可选择文件保存目录，上传成功后自动加入待控文稿列表。
- 新增固定文件接收地址，支持持续接收及设置、修改或移除接收密码。
- 电脑和手机都能查看文件接收开关、连接状态和上传结果。
- 文稿区分手动添加和手机接收，支持按来源筛选和管理。
- 手机端整合计时、演示、会议播控三大页面，支持横向滑动切换。
- 手机文稿列表放大字体、缩短卡片、移除拖动图标，整卡长按即可排序。
- 优化手机端窄屏布局、滚动体验及拖动时的误操作防护。
- 已激活高级版时手机遥控自动就绪，重启远程服务后二维码随状态更新。
- 新增独立只读计时大屏二维码，观看者不能操作计时器。

## 会议背景与讲者

- 新增会议背景素材库，可预览图片、选择默认背景并一键播放。
- 背景支持填充、适应、拉伸、平铺、居中五种显示方式。
- 新增直接切换、淡入淡出、滑动、擦除、缩放等背景切换效果。
- 会场画面可指定观众屏，并可在演示结束后按设置恢复背景。
- 复制屏模式下可在键鼠操作时暂时隐藏背景，停止操作后自动恢复。
- 讲者介绍支持批量导入照片、调整顺序、修改姓名和关联 PPT。
- 手机可播放讲者介绍图片，并在关联 PPT 准备好后安全交接到幻灯片。

## 投影与大屏

- 新增复制、扩展、仅电脑屏幕、仅投影屏幕四种切换操作，电脑和手机均可使用。
- 投影切换加入确认和超时恢复，并修复手机一直显示“切换中”的问题。
- 新增 PowerPoint 演讲者视图辅助设置，与 Windows 投影模式分开控制。
- 优化多屏插拔、分辨率及缩放变化后的计时窗口位置与画面恢复。
- 优化本地计时大屏全屏布局及按钮悬浮操作，修复遮挡和关闭后再次启用问题。
- 改进浏览器只读大屏的时间、页码、逐页计时、配色和字体展示。

## 设置、外观与权限

- 重整九个设置页面，统一中英文名称、选项分组和浅色／深色主题。
- 文件接收、会议背景和讲者设置统一为更紧凑的桌面界面。
- 文字与背景透明度可分别调整，高精度滚轮和设置滚动更顺滑。
- 新增高级功能预览，未激活高级版也能查看相关界面。
- 新增在线取消激活和换机释放设备名额，激活状态可即时刷新。
- 改进启动时授权检查、离线宽限与续期验证，修复错误的“设备数量已满”提示。
- 授权后台增加批量编辑、备注管理和许可证归档。
- 加强手机控制、只读观看和上传接收的权限隔离，配置导出不再包含连接凭据。
