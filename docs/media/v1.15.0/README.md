# v1.15.0 GUI images

Desktop images are rendered from the shipping Slint UI with example data; the disposable documentation renderer selects a CJK font because hosted headless Windows font fallback is unreliable. That font and renderer are not shipped. Mobile images render the shipping HTML/CSS/JavaScript with in-memory example state. Scenario names, presentation paths and connection data are documentation examples, not private user data or physical-device acceptance evidence.
