4. 测试发现稳定 P0/P1 前，不修改产品源码。若发现问题，先记录复现步骤、实际/预期、证据，再做根因+最小修复。

## 2. computer-use 优先原则

只要能通过真实桌面操作完成，就不要把它留给用户：

- 直接点击、拖拽、滚动、输入、切换窗口、使用托盘菜单和快捷键；
- 使用真实 Settings / PC Remote / Timer 窗口，不以离屏渲染替代体验结论；
- 对 GUI 行为可结合截图、窗口几何、HTTP 状态和应用日志交叉验证；
- 如果一次鼠标自动化定位失败，优先重新聚焦窗口、使用键盘导航或重新识别控件，不要立刻把整项测试退回给用户；
- 不建立大型 GUI 自动化框架，不把坐标脚本永久加入项目，不为了测试重构 UI；
- 不伪造外部设备证据。没有真实手机/投影/听觉能力时明确写“仍需用户确认”。

## 3. 必须尽量由 Codex 完成的真实桌面测试

### A. 主程序 / 托盘 / Timer

用真实桌面完成：
- 正常启动与第二实例；
- 托盘菜单可打开 Settings / PC Remote；
- F3 Start -> Pause -> Resume，暂停期间 elapsed 不增长，Resume 不清零；
- F4 Reset；F5 显示/隐藏；
- Timer 浮窗拖动、点击穿透/置顶等当前已有选项至少做基础回归；
- 退出后无残留主程序窗口或遮罩。

### B. Settings 完整体验

用鼠标和键盘实际操作六页 Settings：
- 页面切换、滚动到底、长文本、作者说明、弹窗；
- Apply / Cancel / 恢复默认 / 导入的基本交互；
- 修改一个普通设置但不 Apply，同时去 PC Remote 修改规则/端口/token，再回来 Apply，确认不会覆盖外部保存；
- Tab / Enter / Space 与弹窗遮挡期间背景不可误操作；
- 底栏按钮留白、ScrollView 裁剪、规则编辑卡高度没有重新异常。

### C. PC Remote 规则编辑

直接用真实窗口完成：
- 新增临时规则；
- 单选编辑时长/模式；
- Ctrl 多选 mixed enabled/disabled 后普通 Save，enabled 独立状态不被重写；
- A -> Ctrl B -> Ctrl deselect B，编辑器重新绑定 A；
- batch 8 -> 10 后立即普通 Save，仍保持 10；
- 非法时长有反馈且不保存；
- 端口输入停留数秒不被后台刷新覆盖；
- PC Remote “演示文稿”页只做规则管理，不恢复已删除的放映控制按钮。

如果真实鼠标 Ctrl/Shift 多选可由 computer-use 完成，就必须做，不再仅以模型级单元测试代替。

### D. 混合 DPI / 跨屏

如果当前机器有 150%/125% 或其他混合 DPI 双屏：
- Settings、PC Remote 各沿两屏边缘/角落绕行至少 3 圈；
- 反向往返至少 10 次；
- 主动调整大小后再跨屏；
- 最大化/还原；
- 同一进程关闭并重新打开；
- Timer 浮窗跨屏。

通过标准：无累计变大/缩小、无控件裁切、用户主动尺寸能保持。记录实际屏幕缩放和关键客户区尺寸。

如果当前电脑没有混合 DPI 双屏，不能写“真机通过”，只保留已有 bf00cf0 证据并标明本机条件不足。

### E. 全屏“时间到”遮罩

如果有双屏则两屏都测；只有单屏也必须先完成单屏真实桌面测试：
- 用短倒计时触发“黑屏并显示时间到”；
- 实际观察覆盖屏幕四角和边缘，文字居中；
- 普通点击不解除；
- PPT/WPS 下一页不解除；
- F4 与 Remote Reset 可解除；
- 程序退出清理遮罩；
- “仅提示”和“退出放映”不出现黑色遮罩。

优先使用可丢弃真实 PPT/WPS 放映做一次完整联动，而不是只发 HTTP 翻页命令模拟。

### F. PowerPoint / WPS

只使用临时文稿，通过真实 GUI + 现有状态接口交叉验证：
- 打开文稿、从头放映、从当前页放映；
- 上一页/下一页；
- 放映开始自动计时与结束后的预期行为；
- 至少核对一次临时 range 修改后原 RangeType/StartingSlide/EndingSlide 与 Saved 状态保持；
- Office 暂时无响应/COM 读取失败时，程序不应把 unknown 误判成“放映结束”；
- FlyPPTTimer 退出不应因 Office worker 阻塞而长时间卡住。

不要关闭、保存、强退任何用户真实文稿。

### G. Remote 网络

电脑侧尽量完成：
- 实际 LAN 地址、端口、token、二维码/复制/打开内容一致；
- localhost 与显示的 LAN URL 均做 HTTP 200/403 等鉴权检查；
- token 重生、端口变化、网络变化后 UI 不显示旧值；
- 浏览器实际打开 Remote 页面并执行 Start/Pause/Resume/Reset 和一条临时 PPT 命令。

若有另一台真实设备/Windows Sandbox/现成隔离环境可直接使用，可进一步验证“第二设备 -> LAN URL”；但不要为了这项引入大型 VM/网络测试基础设施。

真正的手机热点扫码，只有在 Codex 能控制真实手机或已有可用移动设备时才宣告通过；否则留为用户最后确认。

### H. 声音 / 安全软件 / 更新交接

通过真实程序 UI 触发：
- 提示音第一次与第二次；
- WAV/MP3，条件已有时再测 WMA/M4A；
- 中文/空格路径；
- TTS；
- 静音切换与恢复；
- 检查运行时没有因为音频路径启动 powershell.exe / pwsh.exe / cmd.exe / wscript.exe；
- 如 Windows Security 或现有安全软件可见，保持启用状态观察是否有拦截，不得关闭安全保护；
- 更新安装交接可继续用无害临时 installer 验证“主程序退出后原生 helper 启动”，不得自动安装真实更新。

如果模型无法判断扬声器主观听感，可以把“播放链路/进程/日志正常”标为 Codex 已验，把“实际听到是否舒服/音量是否合适”留给用户，不能把听感伪报为通过。
