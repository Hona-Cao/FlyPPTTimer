## 1. F01：跨屏沿边绕行导致尺寸异常（P1，必须真机复现）

用户最小复现：把窗口沿两个屏幕边缘拖拽一圈，很快异常放大/缩小。不能改写成偶发且无法复现。分别测试 Settings 与 PC Remote；Timer 浮窗另行核对。

定位重点：`src/window.rs::install_settings_dpi_stabilizer/settings_dpi_proc` 与 Winit/Slint `WM_DPICHANGED`、首帧尺寸恢复、最大化/还原、保存尺寸流程。现有代码在 Winit 处理 DPI 后又用旧客户区比例校正，容易形成两套尺寸控制；这是待测假设，不是凭猜测删除或再叠加一个补丁的理由。

使用临时诊断日志记录：消息顺序、旧/新 DPI、客户区/外框物理尺寸、Slint scale factor、是否正在拖动/吸附/最大化、发生尺寸写入的函数。只记录应用窗口，不采集私人桌面。

修复要求：
- 明确只有一个负责 DPI 尺寸变换的主流程；不从已经被缩放或被约束的尺寸反复乘比例。
- 最大化/贴边吸附/还原不误写为普通窗口基准；不以强制固定尺寸、禁止拖动或关闭 DPI 感知掩盖问题。
- 移动与用户主动调整尺寸分开；保留正常可调整窗口。
- 不添加反复延迟重试、递归 SetWindowPos 或无条件每帧校正。

通过标准：在用户实际 150%/125% 双屏，按同一路径绕边/角落至少 3 圈，再反向往返 10 次，测试最大化和还原、关闭后同进程重开。普通窗口返回同一屏后的逻辑客户区尺寸无累计漂移，控件无裁切，保存/重开没有再放大。报告实际尺寸/缩放与测试步骤；单屏或 headless 不能宣告通过。

## 2. F09：真正的全屏不透明到时遮罩（P1）

用户明确：黑屏必须盖住整个屏幕，阻止继续展示超时内容，不是角落小提示，不是只有文字背景。当前已有虚拟桌面 SetWindowPos 意图，必须复现“小块”并确认实际失败环节。

要求：
- 到时后显示无边框、纯黑、不透明、置顶的遮罩，文字“时间到”居中；覆盖完整屏幕物理区域，包括扩展屏，不能只覆盖 work area 或计时浮窗大小。
- 建议按每个当前显示器的 rcMonitor 创建/布置遮罩，避免一张巨型跨混合 DPI 窗口导致缩放争夺；这是实现建议，不强制新架构。
- Slint 的尺寸/位置与原生 HWND 保持一致，首帧及事件循环稳定后均不回落为默认小窗口；测量实际覆盖而不只检查调用参数。
- 正常结束放映、自动 Stop/Reset 不应把刚出现的到时遮罩立即清掉。明确的主持人“重置/重新开始/解除”才恢复。
- 普通点击黑色区域不应无意解除。保留明确的主持人本地快捷键/Remote 解除与退出通道；不锁系统、不拦截系统安全组合键、不杀其他进程、不更改显示分辨率。
- 不能让讲者仅翻下一页就在投影上继续显示内容。主持人仍能通过明确操作恢复下一位演示。
- “仅提示”和“退出放映”两种模式不得因这项修复变成全屏遮罩。

验证：单屏、混合 DPI 双屏，短倒计时重复 3 轮；覆盖四角和屏幕边缘，没有露出 PPT/桌面区域。验证遮罩持续、下一页不能恢复展示、明确重置可解除、程序退出清理所有遮罩。使用临时文稿，不进行真实文稿风险操作。

## 3. F07：一个连接入口 + 手机热点实际可用（P1）

ChatGPT 的地址枚举修复用于排除原 ipconfig 解析把 DNS/网关当成本机 IP 的问题；这不是对用户现场根因的断言。`.1.4080` 信息不完整，不能凭末尾推断实际地址错误或直接归罪防火墙。

产品要求：一个主要连接 URL 和同一内容的二维码/复制按钮；本地与手机不做两套独立 Remote 服务。PC Remote 演示文稿页仍只保留规则管理。高级诊断可以保留，但不能在主页堆多个让用户猜的链接。

必须核对：
- 电脑连接手机开启的 Wi-Fi 热点；推荐的是电脑在该热点网卡上实际分配的 IPv4，不是手机网关、127.0.0.1、DNS、VPN 或无关虚拟网卡。
- 如有多张活动网卡，验证当前选择规则是否覆盖用户场景；仅有地址排序测试不等于手机能访问。
- UI 显示、QR、复制、服务实际监听端口和 token 一致；重启服务、网络切换、端口替代或 token 更新后不继续显示旧值。
- 监听与鉴权保持正常；不能通过关掉 token 或绑定错误地址“修通”。
- 按 HTTP 返回分类：超时/拒绝连接/403/404/页面正常但命令失败，不混为一类。电脑自身 LAN 地址成功不是跨设备验收。
- 如确需防火墙入站规则，只在明确授权后创建针对当前 EXE/TCP 端口且作用域尽量局域网的规则；考虑手机热点可能被 Windows 识别为 Public。不要关闭整个防火墙或擅自更改网络安全设置。

有真实手机条件时完成扫码、Start/Pause/Resume/Reset、PPT 翻页及服务重启后重连。没有手机条件则先完成电脑侧排查并将最后一次扫码验收留用户，不让用户反复猜 IP。
