## 实际修改

本轮仅修改 `ui/app-window.slint` 中 PresentationWindow 的排版与字号。

- 连接页内容放入现有 Slint ScrollView/VerticalLayout，地址列表和防火墙说明随文字布局，较长内容可以滚动查看，不再受原先固定说明区高度限制。
- 服务状态使用 18px 粗体；推荐地址使用 14px 蓝色较粗文字并允许换行；当前端口与客户端数使用 13px；地址列表和防火墙说明使用 12px。
- 二维码固定 144×144，并保留 contain，窗口缩放不拉伸成非正方形。
- 端口设置和服务操作之间增加分隔与间距，所有原有按钮仍按原顺序分组，remote-action 编号和参数不变。
- 演示文稿列表行高由 40px 调整为 72px：文件名与时长/模式在首行，路径独占第二行，规则启用状态在第三行右对齐。名称 13px，其余字段 12px。文件名宽度避让右侧时长/模式，修正原先首行两块文字区域重叠的问题。
- 已有当前放映状态在列表外顶部保持独立，并加强状态文字；列表选中项继续使用原有蓝色选中背景，不增加状态字段或改变选择逻辑。
- 放大窗口时增加的高度分配给列表；规则操作栏、规则编辑和放映控制区随下缘移动。保留 700×620 最小尺寸。
- 常用打开/放映/翻页区域后增加间距，再排列黑屏/白屏/恢复、结束/关闭和危险退出；退出按钮与既有确认弹层保持原有命令语义。

标准输入控件、所有 command/remote-action/rule-action 回调编号和参数保持原状。未修改 Rust、Web、设置页、Timer、DPI/窗口创建时序或尺寸持久化。

## 仍需用户手测

1. 700×620 默认/最小尺寸及放大后，服务状态、推荐地址和二维码是否醒目。
2. 中英文地址列表、较长 URL、防火墙说明是否换行并可滚动完整查看；全部端口与服务操作是否可达。
3. 长文件名、长路径、时长、模式和启用状态在列表里是否清楚且互不覆盖。
4. 当前放映信息与列表当前选择是否易于区分。
5. 放大窗口后列表是否正确增高，常用操作、屏幕控制及退出按钮是否保持分组且可达。
6. Remote 系统边框拖拽的真实表现，以及 UX-01/02 的已保留效果。

源码与编译检查不代表真实窗口、手机连接或 PowerPoint/WPS 已验收。本轮未生成新手测包，现有 UX01-c11553e 测试包不包含 UX-02/03。
