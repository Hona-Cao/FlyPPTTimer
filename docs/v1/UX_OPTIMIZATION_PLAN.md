## 授权与协作方式

## 目标与边界

目标：信息易读、操作明确、视觉统一、窗口稳定，保持美观、小巧、稳定、快速。

保持 v0.30.2 功能、六页设置结构和顺序、中英文文字、默认值、六套 Timer 配色、用户自定义颜色、计时与提醒行为、规则和 Remote 协议。桌面管理界面的颜色不覆盖 Timer 产品配色。

本计划不包含手机 Web 改版、主题切换开关、设置搜索、实时预览、新配置方案管理、新快捷键或新菜单。新增能力需用户另行确认。窗口创建/DPI/焦点时序、音频优先级、更新和发布脚本不搭车修改。

## 当前源码观察（不是已复现的真机缺陷）

- 设置页深色侧栏与 Remote 浅色导航风格不同；相近的文字、边框和背景颜色散落在多个组件。
- Remote 自绘主按钮在 hover/pressed 时变成浅底，但文字仍白色，存在可读性问题。
- 设置项几乎每行一个圆角边框，长页面容易产生过多视觉分隔。
- FieldRow 右侧控件固定 244px，长路径和中英文长标签需要更合理的空间分配。
- Remote 部分辅助文字为 10～11px，文稿名与状态区域需要结合真实窗口检查。
- Timer 和大屏 Text 设置了 elide；需用户确认长时长、负号、大字号组合是否实际被截断，不能仅凭源码断言存在故障。

## 分轮实施与审核

### UX-01：统一桌面配色（本轮启动）

范围：仅 ui/app-window.slint 中设置窗口、PC Remote 和它们的自绘组件。

- 集中定义常用语义颜色，替换散落的相近色值。
- 设置导航使用浅色面板与蓝色选中态，与 Remote 选中态协调。
- 标题、正文、辅助信息、边框、危险操作统一色彩含义。
- 修正 Remote 主按钮 hover/pressed 白字浅底问题；普通、危险、禁用状态分别表达。
- 保留标准 Button/LineEdit/ComboBox 的原生键盘与输入能力；本轮不换成自绘交互组件。

验收：两窗口风格协调；主按钮普通/悬停/按下均清晰；危险和禁用状态可辨；所有文字、控件顺序与回调保持原有语义。

验证：一次 cargo check 确认 Slint 语法及生成绑定可编译，不新增配色快照测试、不跑完整发布 gate。真实观感由用户手测，源码审核不能替代手测。

### UX-02：设置页信息密度与布局

范围：六页原有设置行、标题和规则区域的排版，不移动选项的信息归属。

- 从每行独立卡片调整为按现有 section 分组的面板；优先简单布局，避免额外状态或模型层。
- 统一标签列和控件列对齐，按时长/路径/按钮内容决定所需空间。
- 长标签允许合适行高，保留完整中英文文字；设置页底部操作条固定可达。
- 文件规则列表保持列表后操作栏，调整列宽和间距。

验收：默认尺寸和最小尺寸下，六页可滚动访问全部设置；长英文标签、路径和规则编辑不互相覆盖；确定/取消/应用可达。

验证：布局编译；如涉及设置模型映射，筛选相关既有设置测试。用户逐页检查两种语言，不宣称覆盖任意 DPI。

### UX-03：PC Remote 可读性与操作层级

- 提高小字号辅助信息的可读性，配套调整行高，而不是单纯放大字体导致截断。
- 连接页突出已有状态、推荐地址和二维码；端口、防火墙信息保持完整但视觉次级。
- 演示文稿页对齐文件名、时长、模式、状态；清楚区分当前选择和正在放映的文稿。
- 在现有路径展示位置优先使用可选取的只读文本；如需新增交互入口，先交审核确认。
- 保留已有放映命令与危险操作确认；不新增确认流程。

验收：长文件名、同名文稿、英文和最小窗口下能辨认目标；规则保存与放映操作不混淆；二维码不因布局变更变形。

验证：仅与改动相关的编译或既有模块测试；真实连接/放映必须由手机和 Office 手测。

### UX-04：已有交互的可用性

先依据用户手测反馈选定具体问题，再执行：

- Tab 顺序、焦点可见性、Enter/Escape 的既有语义。
- 只读路径选取复制、控件禁用关系、滚动时是否误改值。
- 已有状态区的保存、复制、服务重启反馈是否及时清晰。
- 必要时统一标准控件与自绘控件外观，但保留键盘可达性与可访问性；不为统一外观重写全部控件。

验收：用户能明确知道操作对象、是否执行成功、是否还有未应用更改；不新增无必要弹窗。

验证：局部纯视觉无需全量测试；共享行为变化只跑对应设置/Remote 模块测试。

### UX-05：Timer 与真实多屏显示

先记录用户提供的复现条件：窗口尺寸、字号、时间文本、系统缩放、主副屏组合。

- 确认数字完整、负号和小时位不被截断、变化时中心稳定。
- 确认现有配色和透明度在真实演示背景上的可读性。
- 对实际复现的拖动、DPI、圆角、任务栏问题定向修复。

验收：用户复现路径通过；不借机改变默认尺寸、字号、配色、显示策略或计时行为。

验证：只跑被修改的计时/显示逻辑测试，真机多屏效果由用户验收，不建立 GUI 测试系统。

### 2026-09-09 设置与 Remote 回归反馈
