## 产品与交付原则

全部既有功能稳定，现有总体界面方向保留，不删功能、不换主题。Remote 不恢复随机端口或 PC 放映控制按钮；手机 Web Remote 仍有完整演示操作。一个连接入口不等于限制一个客户端。

Codex 整合修复后只交付一个最终绿色包，含对应最新 EXE、干净配置、必要运行库、BUILD.txt 和短说明；不要让用户轮流测多个未收口中间包。统一更新 RC_MANUAL_TEST 中真正残余的体验项目，不再重复历史全部测试。
