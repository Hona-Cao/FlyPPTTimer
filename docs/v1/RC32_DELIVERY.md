## 已实现的产品行为

1. “窗口尺寸与字号”新增自动/自定义模式。自动为默认，按当前时间、页数和字号测量窗口，隐藏宽/高行；字号选项仍可用。自定义显示宽/高，使用用户设置的尺寸，来回切换保留自定义值。自定义过小时可能裁切，不悄悄扩大；需完整容纳内容可切自动。
2. 时间与页数放在同一个垂直居中的文字块，上下布局留白一致。页数字号和颜色默认跟随时间，也可独立设置；支持斜体、左/中/右对齐、位于时间上/下方。修改即时预览，应用才保存，取消恢复已应用设置。
3. 大屏计时所在显示器排除小计时器及其镜像；显示/隐藏操作和刷新不得重新叠加。停用大屏后按原显示设置恢复小计时器。
4. 手机列表增加手动、名称、文件大小、修改时间排序及升/降序。名称使用 Windows StrCmpLogicalW 的数字感知比较；大小和修改时间读取文件实际元数据，元数据不可得的文件在两种方向均排末尾。排序持久化，手动移动切回手动排序。
5. “移除规则”改为“移除文件”，并落实受控成员语义：移除后不再在受控列表出现，也不能继续远程打开/放映/关闭；不删除磁盘文件，不自动关闭或保存 Office 文稿。可通过“添加已打开文件”或电脑端添加重新加入。未受控的已打开文件只出现在独立候选添加区。
6. 正在放映的文件具有区分背景和状态标记。上移/下移加入位置过渡和移动标记；文件标题/拖动柄支持约 0.36 秒长按拖动、浮起卡片、邻居让位和边缘滚动。取消手势不提交；不自动重发操作。网页禁用文字选择、复制和系统上下文菜单，数字输入仍可编辑。

## 本轮仅需用户确认的四组

1. **尺寸和页码样式**：自动/自定义行显隐、即时预览及取消/保存；不同时间/页数字号下上下留白、颜色、斜体、对齐和上下位置。自定义宽高太小允许裁切。
2. **大屏去重**：扩展屏开启大屏+所有屏幕小计时，确认大屏所在屏没有小计时；切换目标、显示/隐藏和停用大屏后恢复正常。
3. **手机排序与拖动**：名称/大小/修改时间升降序、上移/下移动画、长按拖动和边缘滚动、正常滑动不误拖、刷新/重启顺序保留、长按不选字且数字输入可用。
4. **移除与放映高亮**：仅用可丢弃文稿，确认播放文件突出；移除后退出受控列表且不能遥控该文件，磁盘文件与已打开文稿保留，明确重新添加后恢复控制。
