# V1 用户已批准的产品基线覆盖项

本文件记录 **v0.30.2 基线之后，由用户明确提出并已经实施/认可的产品行为调整**。

这些条目不是 Codex 自行扩展功能，而是用户后续要求。若本文件与 `V1_BASELINE_CHECKLIST.md` 冲突，**以本文件为准**；未列出的功能、默认值、文字和行为仍以 v0.30.2 为基线。

不要因为旧基线清单仍保留原条目，就把以下行为恢复回去。

---

## 1. Remote 设置不再暴露“使用随机端口”

用户在 2026-09-09 的真实手测反馈中明确要求 Remote 不再暴露随机端口。

当前批准行为：

- 设置页不显示“使用随机端口”控件；
- 优先使用已保存固定端口；
- 固定端口不可用或无权限时，允许系统分配可用端口；
- 实际替代端口写回配置，并提示用户地址发生变化；
- 旧配置中的 `UseRandomPort` 字段可以继续兼容读取，但不得因此重新增加可见控件或重新采用随机端口产品逻辑。

这项批准调整覆盖 `V1_BASELINE_CHECKLIST.md` 中要求显示“使用随机端口”的旧条目。

---

## 2. PC Remote“演示文稿”页只保留文件规则管理

用户在 2026-09-09 的真实手测反馈中明确要求：PC Remote 的“演示文稿”页复刻设置页文件规则管理，不再承担演示软件运行状态和放映控制。

当前批准行为：

- 保留文件规则列表；
- 保留文件名/路径、时长、模式、启用状态展示；
- 保留添加、删除、清空、保存；
- 保留普通单选、Ctrl 多选、Shift 范围选择；
- 保留批量设置时长/模式；
- 不恢复“演示软件已运行”状态区；
- 不恢复“打开演示文稿 / 从头放映 / 当前页放映 / 上一页 / 下一页 / 跳转 / 黑屏 / 白屏 / 结束放映 / 关闭文稿 / 退出演示软件”等 PC Remote 页按钮。

**手机 / 浏览器 Web Remote 的演示控制能力不受这一调整影响，仍须保留 v0.30.2 的 `ppt.*` 功能。**

这项批准调整覆盖 `V1_BASELINE_CHECKLIST.md` 第 13 节中要求 PC Remote 演示文稿页继续显示完整放映控制的旧条目。
