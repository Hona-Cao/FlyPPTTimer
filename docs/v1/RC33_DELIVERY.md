## 已实施

### 1. 设置与远程控制独立并存

移除打开另一个管理窗口时对现有窗口的互斥隐藏。已有可见窗口优先前置复用；关闭其中一个不连带关闭另一个。现有配置草稿/合并语义保留，不因窗口并存清空未应用的修改。

### 2. 增大滚动与底栏留白

设置、连接和规则列表用布局内边距预留滚动通道，而不是只减去会被 ScrollView 布局覆盖的宽度。设置底部使用独立 96 DIP 操作区，三按钮统一排列并与正文分离。最终软件截图已确认右侧内容不再贴近滚动条；英文外观页示例中卡片右缘到滚动条约 31 像素。实际 DPI/屏幕观感仍需用户确认。

### 3. 应用自身图标

管理窗口、应用拥有的提示框/通用对话框、托盘通知和托盘回退使用产品图标；原生小/大图标显式设置。Win32 resource ID 1 保留其正确整数资源语义。移除托盘失败时退回 IDI_APPLICATION 的路径，改用内嵌产品资源。外部 Office、资源管理器文件夹及文件类型图标不替换。

### 4. 可视选色与 HEX 输入并存

所有已暴露的颜色行提供色块预览、选择颜色及 #RRGGBB 输入。点击色块/按钮打开 Windows 原生色板，支持基本色、自定义颜色及 RGB 调整；选中后回填色值。取消选色不提交；仍遵守设置 Apply/Cancel，页码颜色跟随开关不变。没有新增外部脚本或安装依赖。不是逐像素复制 PowerPoint 主题色界面。

### 5. 被控文件只允许 PowerPoint 文件

共同文件选择器限制 .ppt/.pptx/.pptm，修正标签/模式的 NUL 分隔，不提供“全部文件”；返回路径后再次检查后缀。Settings、PC Remote 以及手机添加已打开文件的候选遵循限制。PDF、图片、Word 等不接受；旧配置的历史条目不自动删除。不能把改扩展名当成内容格式验证，实际文稿仍由 Office 打开验证。

### 6. 手机卡片压缩及排序回跳修复

五个动作固定在一行，缩小卡片内边距、合并状态信息，保留放映高亮、长按拖动和禁止选字。

回跳涉及两条具体路径：命令返回新列表，但随后 GET 曾返回旧缓存；无顺序变化的状态刷新还会取消/重启动画。

现在命令回复前先发布同一份权威状态快照，revision 与快照绑定；客户端拒绝旧 revision、旧命令时段或乱序轮询结果。serverInstance 区分程序重启，避免新进程 revision 从低值开始后无法同步。真正顺序变化时才重排并执行位移动画；普通计时刷新不打断动画。没有关闭轮询，也不自动重发 POST 操作。

## 偶发白屏：已做防护，根因仍未确认

用户只报告一次、目前未能稳定复现。本轮移除 Remote 混用原生 SW_HIDE 与 Slint show 的显示路径，增加 show-generation，丢弃窗口关闭后过期的延迟显示/尺寸回调，显示后请求重绘，并记录可见状态、尺寸和缩放信息。

这属于针对已发现风险路径的修正，不能表述为“已证明彻底修复该白屏”。托管 Windows 检查了 12 轮同进程打开两个窗口、各自关闭/重开、对方保持可见、客户区尺寸非零和图标句柄存在；没有逐帧验证客户区像素内容，不能据此保证所有显卡/DPI 条件均无白屏。

若再次出现，只收集窗口名称、正文空白还是全窗空白、前几步操作和大致时间；不要求用户做压力测试或定位源码。
