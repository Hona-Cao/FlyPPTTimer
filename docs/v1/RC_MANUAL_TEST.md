## Codex RC-2 已实测通过，无需重复

- Portable 启动、第二实例自动退出、F3 开始/暂停/继续（暂停时间固定）、F4 重置、F5 可见状态切换。
- 真实 HTTP token 拒绝/接受、开始/暂停/继续/重置、正计时与超时、LAN 地址本机访问；端口占用回退并写回配置。
- Settings Apply、Cancel 后选择“否”放弃草稿、测试配置导入/恢复默认后界面、磁盘和运行状态同步；重启配置回读。
- 临时目录安装、同版本覆盖安装保留配置、安装版启动、`--show-settings` 模式正常退出、卸载；无残留测试主进程。以上不宣称旧正式版升级或托盘退出通过。

## 仅剩这些最终场景

| 场景 | 简短操作与通过标准 | 为什么还需要 |
|---|---|---|
| 1. 桌面管理与双屏体验 | Timer 右键/托盘进入设置和 PC Remote，关闭后再开；Remote 两页切换，端口输入停顿数秒仍保留，三条测试规则做普通/Ctrl/Shift 选择和一次批量保存。把管理窗口拖到另一屏，启用扩展屏大屏计时，确认窗口可见、文字完整、大屏只在所选扩展屏；最后托盘退出。 | 工具未枚举 Timer/托盘入口；跨屏拖动被工具边界限制拒绝。本机实际 150%/125%，不缺硬件条件。PC 页应只有规则管理，不应恢复放映控制按钮。 |
| 2. PowerPoint / WPS 实际工作流 | 各用临时文稿完成放映、翻页/跳转、黑白屏/恢复、结束，观察自动开始/结束计时。若日常使用多放映窗口，交错打开 A/B 并切换活动文稿：只能控制匹配窗口；目标不明时应提示失败，已有放映和计时不应误停。 | 本轮 WPS 已打开用户文稿，按安全规则未控制、关闭或强退 Office；多窗口真机语义不能由纯逻辑测试代替。 |
| 3. 手机真实连接 | 手机与电脑同一局域网，扫描 Remote 地址，执行开始、暂停、继续、重置；状态及时更新。 | 本机 LAN 地址成功不等于跨设备链路或防火墙通过。 |
| 4. 听一下 | 选择平时使用的提示音并启用语音，各触发一次，确认声音可听、内容正确、静音状态符合预期。 | 系统 WAV/MP3、TTS 调用和应用提示路径已执行，但无法代替人耳判断。 |
| 5. 旧正式版升级（仅安装版用户） | 备份现有配置后升级，确认原规则/设置保留，程序可启动。便携版用户可跳过。 | 本轮隔离新装/同版本覆盖/卸载已通过；没有以用户旧正式安装做覆盖升级。 |

这些未验收项是候选版最终确认，不是已知故障。除实际发现 P0/P1 外，不继续改源码或增加测试框架。
