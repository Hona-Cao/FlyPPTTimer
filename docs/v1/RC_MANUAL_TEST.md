# RC-1 手工验收清单

在干净用户配置或可恢复的测试配置下，使用 `target/release/FlyPPTTimer.exe` 执行以下场景。每项记录“通过 / 失败 + 复现步骤”；PowerPoint、WPS 和真实多屏操作需要在目标机器上完成。

| # | 场景与步骤 | 通过标准 |
|---|---|---|
| 1 | 启动应用，使用 `F3` 开始、再次 `F3` 暂停，再次 `F3` 继续；用 `F4` 停止并重置，`F5` 显示/隐藏计时窗。 | 状态和显示按顺序变化，暂停期间时间不增加。 |
| 2 | 分别测试倒计时、正计时和超时；触发两次提前提醒与结束提醒。 | 数值、颜色、闪烁和提示各触发一次，重置后可再次触发。 |
| 3 | 在设置中修改提醒声音，导入 WAV/MP3，启用 TTS 后保存并重启。 | 声音可预览并在提醒时播放；TTS 文案和开关持久化。 |
| 4 | 修改设置后点“取消”；另开实例或编辑配置后使用“导入配置”，再执行“恢复默认”。 | 取消不写入草稿；导入先校验并合并；恢复默认后重启仍为默认值。 |
| 5 | PC Remote 连接页启动/停止服务、复制地址；演示文稿页添加规则，普通/Ctrl/Shift 选择并批量改时长和模式。 | 固定端口优先、占用时提示替代端口；PC 页只显示规则管理；规则保存后回读一致。 |
| 6 | 用手机或浏览器 Web Remote 连接，测试计时开始/暂停/继续/重置及 `ppt.*` 上一页、下一页、跳转、黑屏、白屏、结束。 | Token 鉴权有效，Web Remote 保留完整演示控制；状态同步及时。 |
| 7 | 在 PowerPoint 和 WPS 中各打开两份文稿，交错启动放映，测试上一页/下一页/跳转/黑白屏/结束；切换活动文稿后重复。 | 命令作用于活动文稿对应的放映窗口；多窗口无法匹配时给出明确错误，不误控第一窗口。 |
| 8 | 在双屏环境启用大屏计时，调整位置、最小化、最大化，再切换 DPI 缩放。 | 大屏只出现在扩展屏；位置和尺寸可恢复，缩放后无明显裁切或错位。 |
| 9 | 从便携 ZIP 解压后运行，修改配置并重启；运行安装器、升级覆盖安装，再卸载。 | 便携配置留在程序目录；安装版升级保留配置；退出和卸载不残留运行进程。 |
| 10 | 关闭主窗口、托盘退出、演示软件已由用户启动时分别执行“退出演示软件”和“强制退出”。 | 仅关闭 FlyPPTTimer 时不误关用户拥有的演示进程；强制退出明确提示未保存内容风险。 |
