## 1. 跨屏与界面——用同一条已报告路径确认一次

正常双击新绿色版，保留原 150%/125% 双屏设置；按之前沿两个屏幕边缘绕一圈的方式拖动 Settings 和 PC Remote，再反向返回。

通过标准：不累计放大/缩小，最大化/还原及同一进程关闭重开尺寸合理；确定/取消/应用不贴边；时长/模式卡片紧凑；滚动条不遮挡控件；打开“作者的话”能从首段读到末句，必要时滚动，顶部没有蓝色装饰条。

从 Timer 右键和托盘打开窗口、最后正常退出，不能白屏或只留任务栏。其余规则多选/批量、草稿合并、端口输入等开发回归由 Codex 先做，不因这次 UI 调整要求用户重新跑历史全部清单。

## 2. 手机热点——一个地址一次连接

手机打开热点，电脑连接该热点；使用新版本提供的唯一主要 URL/二维码，让同一手机浏览器连接。执行开始、暂停、继续、重置，必要时与演示工作流合并检查。

通过标准：推荐地址为电脑在该网络上的实际地址，二维码/复制一致，手机可以进入并控制；服务重启或网络变化后信息更新，不依赖关闭防火墙或取消 token。

若失败，记录手机显示的错误类型（超时、拒绝、403、404或页面正常但操作失败）。不公开 token/二维码；电脑侧网卡、监听、路由及授权防火墙排障由 Codex 做，不要求用户反复换 IP 尝试。

## 3. 声音与安全软件——听一次，观察一次

保持安全软件启用，用平时的提示音触发首次和第二次提醒；清除自定义音频后再单独测试 TTS。原逻辑优先自定义音频，不要求两者同时播放。

通过标准：声音完整、语音正确、静音恢复正常，音频链路不再拉起 PowerShell。若安全软件仍提示，记录产品名称与不含隐私的拦截项/父进程信息，由 Codex 定位；不要关闭防护、增加全盘白名单或用隐藏脚本规避。

运行库签名或构建通过都不能保证所有杀毒产品永不拦截，必须按现场结果记录。

## 4. 全屏“时间到”与演示——只用临时文稿

先保存并关闭真实工作文件，打开可丢弃的测试 PPTX。设置短倒计时和“黑屏并显示时间到”，在演示过程中等到时间结束。

通过标准：黑色不透明遮罩盖住完整屏幕及扩展演示屏，四角和边缘不露出 PPT/桌面，不只是小提示框；普通翻页/普通点击不继续露出演示，明确的主持人重置/解除/下一轮操作能恢复，退出程序不遗留黑屏。

“仅提示”和“退出放映”仍各自符合设置。PowerPoint/WPS 各自的正常翻页、目标文稿、原本未保存内容和错误恢复由 Codex 先用临时文稿验证。用户只补自己的真实工作流体验，不承担风险故障注入。
