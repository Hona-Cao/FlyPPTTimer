# FlyPPTTimer v1.19.2（正式版）

发布日期：2026-10-26。

## 1. 新增单行计时模式
- 支持单行与双行显示自由切换。
- 单行模式可选择显示总时间、逐页计时和页码。
- 单行模式下，演讲控制条的四个按钮横向排列；双行模式保留 2×2 布局。

## 2. 优化窗口尺寸与字号
- 支持自定义计时窗口宽度和高度，并实时预览尺寸变化。
- 单行与双行共用字号设置。
- 窗口空间不足时自动扩大窗口以容纳文字，不会自动缩小字号。
- 切换到自定义尺寸时，宽高参数与当前窗口实际尺寸保持一致。
