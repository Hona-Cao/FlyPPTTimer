# FlyPPTTimer 1.19.3 更新说明

本次更新修复三处影响正常放映的问题，并调整手机端关闭文稿与退出演示软件的行为。功能与设置项同 1.19.2，无新增功能。

## 1. 切换默认演示软件后，手机遥控无法打开文稿

- 修复前：默认程序由 WPS 改为 PowerPoint（或反向）后，手机端打开文稿仍调用原程序，导致打开失败或打开到错误的程序。
- 修复后：始终调用当前 Windows 默认演示软件。

## 2. 放映结束后立即打开下一份文稿可能卡住

- 修复前：上一份放映退出后立即打开下一份，偶发停留在加载状态，需重启应用。
- 修复后：自动重试；仍无法打开时改用系统默认方式打开，并接管实际打开的文稿。原文稿不保存、不关闭。

## 3. 放映过程中计时可能归零并重新开始

- 修复前：同一场放映进行中，偶发被判定为新一场放映，计时回到起点。
- 修复后：仅在实际开始新一场放映时重新计时。

## 4. 手机端关闭文稿与退出演示软件的行为调整

- 手动打开、不在文件列表中的文稿，可通过手机远程关闭。
- "退出演示软件"会关闭当前 PowerPoint / WPS 实例内的所有文稿（含手动打开），其他 Office 窗口不受影响；执行前需确认，未保存的修改将被丢弃。

## 升级说明

- 安装版可直接覆盖 1.19.2，个人设置与文件规则保留。
