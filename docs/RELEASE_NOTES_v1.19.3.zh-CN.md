# FlyPPTTimer 1.19.3 更新说明

本版修了三处会打断演示的问题，另外把手机端的"关闭文稿 / 退出演示软件"说明清楚了。功能和设置项与 1.19.2 一致，没有新增功能。

## 1. 换了默认演示软件之后，手机遥控打不开文稿

- 之前：先把 WPS 设成默认程序，后来又改回 PowerPoint（或反过来），再用手机打开文稿时，程序仍然去找原来那个软件，结果打不开，或者打开到了错的程序里。
- 现在：按你当前在 Windows 里设置的默认演示软件打开，不会再沿用上一次的选择。

## 2. 一份放映结束后，紧接着打开下一份文稿会卡住

- 之前：上一份放映刚退出就打开下一份，偶尔会一直停在加载中，只能重开软件。
- 现在：会自动重试；如果仍然打不开，就改用 Windows 默认方式打开，并接管真正打开的那份文稿。上一份文稿不会被保存，也不会被关闭。

## 3. 放映中途计时会自己归零、重新开始

- 之前：同一场放映还在进行时，计时偶尔会被当成"又开了一场新的"，时间跳回起点重新计时。
- 现在：只有真正开始新的一场放映才会重新计时；同一场放映中的状态波动不会再打断计时。

## 4. 手机上的"关闭文稿""退出演示软件"更明确了

- 手动打开、不在文件列表里的文稿，现在也能用手机远程关闭。
- "退出演示软件"关闭的是当前这个 PowerPoint / WPS 里的所有文稿（包括手动打开的），其他 Office 窗口不受影响；执行前会先请你确认，并明确提示未保存的修改会被丢弃。

## 升级说明

- 安装版可以直接覆盖 1.19.2，个人设置和文件规则都会保留。
- 如果你没遇到过上面这些问题，继续用 1.19.2 也不影响。
