# FlyPPTTimer 1.19.4 Release Notes

- Improved detection and phone control of presentations opened directly from USB drives, while keeping the previous speaker's document open during handoff.
- Improved PowerPoint/WPS opening, switching, and editor slide-number synchronization, with faster status updates on the phone.
- Fixed occasional presentation loading stalls, timer ownership during speaker changes, and end-of-time slideshow exit issues.
- Fixed applying multiple settings at once, including hours, minutes, and seconds.
- Improved compatibility with older Windows 10 versions: manual updates on older systems, existing update preferences on newer systems.
- Reduced redundant background presentation monitoring, file metadata work, and waiting notifications.
