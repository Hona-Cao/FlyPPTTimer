# FlyPPTTimer v1.19.2 (Stable Release)

Release date: 2026-10-26.

## 1. New Single-Line Timer Mode
- Switch freely between single-line and two-line layouts.
- Choose whether to display the total time, per-slide timer, and page number in single-line mode.
- The speaker control bar uses a horizontal four-button layout in single-line mode and retains the 2×2 layout in two-line mode.

## 2. Improved Window Sizing and Font Consistency
- Customize the timer window width and height with live size previews.
- Share font-size settings between single-line and two-line layouts.
- When the text needs more space, the window expands instead of automatically shrinking the font.
- Switching to custom sizing initializes the width and height from the current window dimensions.
