# FlyPPTTimer v0.30.0

本版本根据 0.20.9 实机测试意见，修复设置窗口崩溃，并重新定义大屏计时器和设置下拉控件。

- 大屏计时器现在是可自由调整大小的标准窗口，并支持最小化和最大化。
- 大屏模式只允许在扩展屏显示，主屏幕不会出现在目标列表中。
- 没有扩展屏时，大屏模式不可启用，目标屏幕下拉框不显示。
- 大屏模式关闭时，目标屏幕控件直接将原圆角背景切换为灰色，不再叠加另一层色块。
- 修复点击托盘右键菜单“设置”后程序崩溃退出。根因是大屏窗口错误释放了 WinForms 共用字体。
- 设置下拉框统一为无实线边框、无阴影的圆角样式。

本测试版仅在本地构建，尚未发布到 GitHub 或 Gitee。
