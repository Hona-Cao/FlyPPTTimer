# Installer language asset

`ChineseSimplified.isl` is the Simplified Chinese translation distributed in
the official [Inno Setup source repository](https://github.com/jrsoftware/issrc/blob/main/Files/Languages/ChineseSimplified.isl).

The translation identifies Zhenghan Yang (Kira) as its maintainer. It is kept
in this repository because the standard Inno Setup 6.7.3 installation does not
install that language file locally, while FlyPPTTimer's release build must be
reproducible on a clean Windows machine.
