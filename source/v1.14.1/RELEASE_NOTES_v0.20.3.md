# FlyPPTTimer v0.20.3

## 中文

- 新增 English / 简体中文 / 跟随系统界面语言。
- 安装器自动读取 Windows 显示语言，同时允许安装前手动选择英文或简体中文。
- 便携版首次启动按系统语言显示。
- 手机网页遥控默认跟随设备语言，并提供独立语言选择。
- 切换语言不会覆盖计时设置、文件规则或远程控制配置。
- 补齐桌面界面、规则编辑器、远程控制、动态状态和确认弹窗的英文翻译。
- 切换语言时可选择立即自动重启，或等到下次启动时应用。
- 修复英文设置页无修改时错误提示存在未应用修改的问题。
- 文本外框会按翻译内容自适应；短文本保持单行，长文本自动换行。

## English

- Added English, Simplified Chinese, and Follow system display-language options.
- The installer detects the Windows display language and lets users choose English or Simplified Chinese.
- The portable edition follows the system language on first launch.
- The phone/browser remote follows the device language and includes its own selector.
- Changing languages preserves timer settings, presentation rules, and remote-control configuration.
- Completed English translations across desktop UI, rule editors, remote control, dynamic status messages, and confirmation dialogs.
- Language changes can restart the app immediately or take effect on the next launch.
- Fixed the false “unapplied changes” warning when opening English settings without editing anything.
- Text containers now adapt to translated content, keeping short labels on one line and wrapping longer text.
