# RC3.3 绿色测试版：只检查本轮四组

先从托盘退出旧版，再解压到新的可写文件夹运行 FlyPPTTimer.exe。同目录 DLL 请保留，不覆盖原配置。手机刷新旧网页后再测试。Office 仅使用可丢弃文稿副本。

## 1. 两个管理窗口、留白、图标和重新打开

同时打开“设置”和“远程控制”，关闭其中一个，另一个应保留；重新打开时不丢另一个窗口或未应用的修改。看看滚动条与主体、底部“确定／取消／应用”与主体的留白是否足够，任务栏、Alt-Tab、窗口和本软件弹窗是否使用软件图标。

按日常使用方式开关几次即可，不要求反复压力测试。之前的偶发空白尚未稳定复现；本轮移除了混用原生隐藏和 Slint 显示的路径，给过期延迟回调加保护，并记录窗口显示、尺寸信息，不能据此宣称所有空白都已消除。若再出现，只需提供哪个窗口、是否只有正文空白或整个窗口空白、前几步操作和大致时间，便于核对日志。

## 2. 色板、自定义颜色与输入色值

在“行为设置”和“外观与显示”的颜色行，点色块或“选择颜色”。可以选常用色，也可以在自定义颜色区用鼠标及 RGB 调整；色值输入框保留，选色后应同步为 #RRGGBB。

取消选色不改变原值；设置“应用”保存，设置“取消”放弃未应用修改。页数颜色的“跟随时间”规则保持。无需输入色值也应能完成配色。

## 3. 只允许添加 PowerPoint 文件

分别从设置和远程控制添加文件，选择器只允许 .ppt、.pptx、.pptm。PDF、图片、Word 等不应加入；手工在文件名框输入其他文件也不能绕过限制。旧配置中的历史项目不会被本轮自动删除。

## 4. 手机文件列表密度和排序动画

每个文件下方的五个操作应在同一行，卡片不再为这些按钮占两行。长文件名仍应能辨认，正在放映项保留高亮。

试按名称／大小／修改时间排序、升降序、上移／下移、长按拖动。等待几次自动刷新，顺序不应出现“新顺序→旧顺序→新顺序”的回跳，状态刷新也不应中途重启动画。正常滑动不应误拖；重新打开网页或重启程序后顺序仍保留。重启程序后手机能重新同步，不因修复用的版本号归零而卡住。
