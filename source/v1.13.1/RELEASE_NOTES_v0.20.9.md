# FlyPPTTimer v0.20.9

本版本根据 0.20.8 实机测试意见，进一步明确远程控制的信息层级，并优化多显示器设置和下拉控件交互。

- 远程控制顶部使用独立导航区域，模块入口与页面操作按钮不再混淆。
- 局域网说明合并到一个位置，并说明手机热点、电脑热点也可用于建立控制网络。
- 手机控制端自动跟随设备系统语言，不再提供手动语言切换。
- “外观与显示”首先提供普通计时器窗口开关，并新增“大屏计时模式”分组。
- “所有屏幕同时显示”和“单屏显示屏幕”采用互斥交互，前者启用时后者自动禁用。
- 设置下拉框统一为完整圆角矩形，文字居中，并修复滚轮滚动不跟手的问题。

本测试版仅在本地构建，尚未发布到 GitHub 或 Gitee。
