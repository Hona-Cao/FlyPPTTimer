# RC3.4 手工体验

退出旧版，解压到新文件夹后运行。新默认值仅在新配置或恢复默认时生效；复用旧配置会保留已保存的个人设置。

1. 页数：默认不跟随时间字号，12，下方，右对齐。用一份 PPT 确认实际页数显示。
2. 外观：切换小、中、大圆角；拖动不透明度、水平/垂直微调滑块，数值和浮窗即时变化。点取消并放弃后恢复；点应用后重开保留。
3. 输入：修改字号或时长，按回车或点空白/其他控件，插入光标停止闪烁。底栏修改后显示“有未保存的修改”，应用后显示“已保存”。
4. 主题：外观与显示页顶部切换深色，确认设置六页、Remote、批量编辑和说明卡片文字清晰。手机页可跟随电脑或单独选浅/深色。Windows 自带对话框保留系统主题。
5. 手机打开受控 PPT：文稿编辑窗口应最大化并前置，不是自动开始放映。分别确认你实际使用的 PowerPoint/WPS。

之前已通过的 RC3.3.1 项目不要整套重测。
