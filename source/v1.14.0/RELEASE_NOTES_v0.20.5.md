# FlyPPTTimer v0.20.5

## 中文

- 远程控制窗口取消左侧栏，改为顶部两个独立圆角按钮：“远程连接”和“演示文稿”。
- 远程连接页重构状态栏、二维码连接和浏览器访问区域；演示文稿页重构工具栏、列表、文稿详情、放映控制与退出软件卡片。
- 只读和禁用控件使用明确的灰色状态；删除、保存、浏览和放映按钮依据当前选择、修改内容及放映状态启用。
- 设置导航栏增加垂直空间并内缩绘制，避免底部圆角被裁切。
- 中英文文字、窗口最小尺寸及 100%–175% DPI 自适应布局已纳入自动测试。

## English

- Replaced the remote-control sidebar with two independent rounded top navigation buttons: Remote connection and Presentations.
- Rebuilt the connection status, QR access, browser access, presentation list, details, slide-show controls, and quit card.
- Read-only and disabled controls now use distinct full-control styling; action availability follows the current selection, edits, and slide-show state.
- Added vertical room and inset painting to the Settings navigation so its lower rounded corners remain visible.
- Added automated bilingual and logical layout coverage for 100%–175% display scaling.
