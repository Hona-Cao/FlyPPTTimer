# FlyPPTTimer v0.20.4

## 中文

- 设置导航栏固定为单行；空间不足时自动扩宽窗口，保证所有导航项完整显示。
- 远程连接页删除端口标签和输入框，新安装默认使用固定端口 `4080`；旧版随机端口配置升级时迁移到 `4080`，已设置的固定端口继续保留。
- 删除浏览器地址右侧不再需要的“选择”按钮，地址由程序自动选择。
- 保留 v0.20.3 的中英文界面、语言切换重启提示和自适应文本布局。

## English

- Settings navigation now stays on one line, and the window expands automatically when necessary.
- Removed the port label and input from the remote-connection page; new installations and upgrades from the old random-port default use `4080`, while explicitly configured fixed ports are preserved.
- Removed the obsolete address selector button; the app selects the browser address automatically.
- Retained the bilingual UI, language-change restart prompt, and adaptive text layout from v0.20.3.
