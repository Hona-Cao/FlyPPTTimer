# Contributing to FlyPPTTimer

FlyPPTTimer is transitioning from a public-source project to closed-source freeware after v1.15.0.

## What is still welcome

Bug reports, usability feedback, feature requests, translations, reproducible test cases, and documentation corrections are welcome through the issue tracker.

Please include the application version, Windows version, PowerPoint/WPS version, steps to reproduce, expected result, and actual result. For display issues, include scaling and monitor arrangement. For phone-remote issues, include browser and network type. Remove live QR codes, access URLs, private paths, tokens, and sensitive presentation content from screenshots and logs.

## Source-code contributions

Historical releases up to and including v1.15.0 remain available under the MIT License that accompanied them. Future proprietary source development is not intended to accept unsolicited public code contributions unless the maintainer explicitly requests them.

If the maintainer invites a code contribution for a later proprietary version, licensing and copyright terms must be agreed separately before code is incorporated.

## Releases

Only the maintainer may designate a build as an official FlyPPTTimer release. Do not publish, mirror, repackage, or distribute unofficial builds under the FlyPPTTimer name or icon. See [LICENSE](LICENSE) and [TRADEMARKS.md](TRADEMARKS.md).
